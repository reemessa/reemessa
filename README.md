### 🚀 About Me

Software engineer and architect with 11+ years in Java and Spring Boot, building large-scale humanitarian systems. On the side, I build tools for people who read, and systems for bookstores and publishers, with a focus on Arabic.

🔭 &nbsp;I'm currently working on **Waraq (readwaraq.com) — a bilingual Arabic/English home for readers**  
👯 &nbsp;I'm looking to collaborate on **tech for Arab publishers, bookstores and readers**  
💬 &nbsp;Ask me about **Java, Spring Boot, software architecture**  
⚡ &nbsp;Fun fact: **I build the apps I wish I had as a reader**
